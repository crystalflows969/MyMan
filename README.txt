SORRY MY MAN 💌 — NO-IMAGE EDITION

This version has no photos, image tags, or images folder. It is a single-page static website.

Included:
- Black, blue, red and green romantic aesthetic
- Starry background, floating sparkles and ambient emoji twinkles
- Cute decorative emoji ribbons and love-note cards
- Fireworks on the opening surprise and chapter transition
- YES = lots of floating hearts and kiss emojis
- NO = crying emojis only

DEPLOY WITHOUT INSTALLING GIT
1. Download and extract sorry-my-man-no-images.zip.
2. Open your GitHub repository.
3. Click Add file > Upload files.
4. Upload index.html (replace the old one if prompted).
5. Click Commit changes.
6. If the repository is connected to Vercel, it will redeploy automatically.
   Otherwise, go to Vercel > Add New > Project and import the repository.
7. Framework Preset: Other. Leave Build Command empty and deploy.
